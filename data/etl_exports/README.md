# ETL Exports - Transformed Data for Dashboard

## 📁 Purpose

This folder contains **transformed data exports** from the ETL pipeline. These are the **primary data source** for the dashboard.

## ⚡ Key Differences

### ❌ Raw Data (`data/f1_results_joined.csv`)
- Simple JOIN of 3 CSV files (races + results + drivers)
- **NO transformations applied**
- Contains null positions (DNF, DNS, DSQ)
- Data types not validated
- 26,759 raw records

### ✅ Transformed Data (`data/etl_exports/f1_results_latest.csv`)
- **Full ETL pipeline applied**
- Spark-based data quality checks
- **Transformations:**
  - ✅ Filter out null positions (DNF/DNS removed)
  - ✅ Cast year/round/position to int
  - ✅ Cast points to float
  - ✅ Data validation & cleaning
- ~24,000 cleaned records (after filtering)

## 🔄 How Data Gets Here

### Step 1: Run ETL Pipeline
```bash
docker-compose up -d postgres
python etl/etl_pipeline.py
```

### Step 2: ETL Process
```
1. Extract from CSV files (data/*.csv)
2. Transform with Spark (filter, cast, validate)
3. Load to PostgreSQL (f1_results_transformed table)
4. Export to CSV (data/etl_exports/f1_results_latest.csv) ← YOU ARE HERE
5. Save metadata (artifacts/etl_metadata/etl_run_info.json)
```

### Step 3: Dashboard Auto-Detects
```python
# dashboard/unified_app.py
def load_results():
    # Priority 1: ETL export (THIS FOLDER)
    etl_data = load_etl_export()  # Reads f1_results_latest.csv
    if not etl_data.empty:
        return etl_data, 'etl'
    
    # Priority 2: Database (fallback)
    # Priority 3: Raw CSV (temporary fallback)
```

## 📊 Output Files

### `f1_results_latest.csv`
**Status:** Generated by ETL pipeline  
**Content:** Transformed race results  
**Auto-updated:** Every time ETL runs  
**Used by:** Dashboard (Classic ML section)

**Schema:**
```csv
raceId,year,round,name,driverId,surname,position,points
18,2008,1,Australian Grand Prix,1,Hamilton,1,10.0
```

**Columns:**
- `raceId` (int) - Race identifier
- `year` (int) - Season year
- `round` (int) - Round number  
- `name` (str) - Race name
- `driverId` (int) - Driver identifier
- `surname` (str) - Driver surname
- `position` (int) - Finishing position (nulls filtered out!)
- `points` (float) - Points scored

### Auto-Refresh

Dashboard checks for new data every **5 minutes** (cache TTL):
```python
@st.cache_data(ttl=300)  # 5 minutes
def load_etl_export():
    export_path = BASE_DIR / "data" / "etl_exports" / "f1_results_latest.csv"
    return pd.read_csv(export_path)
```
